# Precatórios & RPVs — Consulta e Investimento

Ferramenta de busca e consulta de precatórios e RPVs via API DataJud (CNJ).

## Como usar

Abra o `index.html` no navegador ou acesse via GitHub Pages.

## Funcionalidades

- **Buscar Processos** — consulta via API DataJud por nome, número ou CPF
- **Modo Prospecção RPV/INSS** — busca direcionada para encontrar RPVs com cálculo homologado
- **Como Consultar** — guia passo a passo para TRF2 e municípios RJ
- **TRF6** — consulta de Ofício Requisitório (Minas Gerais)
- **Investir / Comprar** — plataformas de marketplace e critérios de avaliação
- **Vender** — passo a passo da cessão de crédito
- **Todos os Links** — portais dos tribunais e mercado secundário

## Publicar no GitHub Pages

1. Faça upload desta pasta para um repositório no GitHub
2. Vá em **Settings → Pages**
3. Em **Source**, selecione `main` branch e pasta `/root`
4. Clique **Save** — o site estará disponível em `https://seuusuario.github.io/nome-do-repo`

## API

Utiliza a [API Pública DataJud do CNJ](https://datajud-wiki.cnj.jus.br/api-publica/).
